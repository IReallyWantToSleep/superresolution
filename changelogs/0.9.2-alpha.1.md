# 0.9.2-alpha.1

### ✨ 新增

* 光影接口
  * 新增 Iris 扩展功能
* 平台
  * 新增 Minecraft 26.3 支持（Fabric、NeoForge）
* 日志与诊断
  * 新增帧节奏采集窗口与 CSV 导出，记录渲染、帧生成及 Vulkan 呈现事件

### 🔧 改进

* 帧生成
  * 改进异步帧生成的呈现流程
  * 改进 Vulkan 帧节奏估计与呈现时序跟踪

### 🐛 修复

* 算法
  * 修复切换超分算法时旧算法资源未及时释放
* 渲染
  * 修复窗口最小化时 Vulkan 呈现异常
  * 修复 Vulkan 设备销毁时的同步问题
* 低延迟
  * 修复 Vulkan 帧生成 NVIDIA Reflex 低延迟标记异常

### ✨ Added

* Shader Interface
  * Added Iris extension feature
* Platform
  * Added Minecraft 26.3 support (Fabric, NeoForge)
* Logs and Diagnostics
  * Added a frame-pacing capture window and CSV export that records rendering, frame generation, and Vulkan presentation events

### 🔧 Improved

* Frame Generation
  * Improved asynchronous frame-generation presentation flow
  * Improved Vulkan frame-pacing estimation and presentation timing tracing

### 🐛 Fixed

* Algorithms
  * Fixed previous upscaling algorithm resources not being released when switching algorithms
* Rendering
  * Fixed Vulkan presentation issues when the window is minimized
  * Fixed synchronization during Vulkan device teardown
* Low Latency
  * Fixed NVIDIA Reflex low-latency markers during Vulkan frame generation
