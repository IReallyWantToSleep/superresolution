Minecraft に組み込みの超解像アルゴリズムを導入し、パフォーマンスと画質を向上させます。

# 対応アルゴリズム

* FSR1
* FSR2
* FSR3
* SGSR2
* SGSR1
* DLSS
* XeSS

# その他の機能

* シェーダーパック内の超解像対応、[ドキュメント](https://sr.187j3x1-114514.org/docs/Shaderpack-Interface-documentation/)

# 互換性

* Sodium 正常に動作
* Iris 正常に動作
* Distant Horizons 正常に動作
* Embeddium 正常に動作
* Voxy 正常に動作
* OptiFine 非対応

# 要件

## システム要件

* Windows 10/11 x64
* Linux x64

### Android デバイスについて

Android のモバイル端末はサポートしません。

## グラフィックカード要件

### 推奨

* OpenGL バージョン 4.3 以上対応
* OpenGL 拡張 `GL_ARB_direct_state_access` `GL_ARB_gl_spirv` `GL_ARB_clear_texture` `GL_EXT_memory_object` `GL_EXT_semaphore` 対応
* Vulkan バージョン >= 1.2 対応

### 最小

* OpenGL バージョン 4.1 以上対応
